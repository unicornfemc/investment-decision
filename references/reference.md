## 1. 估值方法详解

### 1.1 PE（市盈率）估值

**适用场景**：盈利稳定的成熟企业

**计算公式**：PE = 股价 / 每股收益（EPS）

**判断标准**：

| PE区间 | 判断 | 适用情景 |
|--------|------|----------|
| <10x | 低估 | 困难行业、周期底部 |
| 10-20x | 合理 | 稳定增长企业 |
| 20-30x | 合理偏高 | 成长型企业 |
| >30x | 高估 | 需要高增长支撑 |

**注意事项**：
- 不适用于亏损企业
- 周期性行业在底部时PE失真
- 用滚动PE（TTM）而非静态PE
- 对比行业平均和自身历史

**PEG估值法**：
- PEG = PE / 净利润增速
- PEG < 1 = 相对低估
- PEG > 1.5 = 相对高估

---

### 1.2 PB（市净率）估值

**适用场景**：重资产企业、银行、保险

**计算公式**：PB = 股价 / 每股净资产

**判断标准**：

| PB区间 | 判断 | 适用情景 |
|--------|------|----------|
| <1 | 低于净资产 | 价值陷阱或低估 |
| 1-2 | 合理 | 大多数情况 |
| 2-3 | 偏高 | 优质公司 |
| >3 | 高估 | 需要强护城河支撑 |

**适合行业**：银行、保险、地产、制造业

---

### 1.3 DCF（现金流折现）估值

**适用场景**：现金流稳定、可预测性强的企业

**核心假设**：
1. 未来现金流预测（通常5-10年）
2. 折现率（8%-12%）
3. 永续增长率（2%-4%）

**简化DCF公式**：

```
合理股价 = 自由现金流 × (1+g) / (r-g)
其中：g = 永续增长率，r = 折现率
```

**注意事项**：
- DCF对假设敏感度高
- 适用于消费、医药等稳定行业
- 不适用于高增长、高不确定行业

---

### 1.4 股息率估值

**适用场景**：高分红企业

**计算公式**：股息率 = 每股股息 / 股价

**判断标准**：

| 股息率 | 判断 |
|--------|------|
| >5% | 高吸引力 |
| 3-5% | 有吸引力 |
| 2-3% | 合理 |
| <2% | 无吸引力 |

**核心指标**：
- 每股股息（DPS）
- 分红率（ payout ratio）
- 股息保障倍数

**注意事项**：
- 还要看分红能否持续
- 高息可能是价值陷阱（股价暴跌）

---

### 1.5 综合估值矩阵

| 企业类型 | 首选估值 | 次选估值 | 避免 |
|----------|-----------|----------|------|
| 成长股 | PEG | PS | PE（盈利小） |
| 成熟消费 | PE + 股息率 | DCF | PS |
| 银行保险 | PB | 股息率 | PE（失真） |
| 周期股 | PB | PE（周期顶部） | DCF |
| 科技股 | PS + 用户数 | PEG | PE（亏损） |
| 公用事业 | 股息率 | DCF | PE（受限） |

## 2. 护城河评估框架

### 巴菲特护城河分类

| 护城河类型 | 特征 | 案例 |
|------------|------|------|
| **品牌优势** | 消费者愿为品牌支付溢价 | 茅台、苹果、爱马仕 |
| **网络效应** | 用户越多，产品价值越高 | 微信、Visa、Meta |
| **转换成本** | 用户更换产品成本高 | Oracle、Salesforce |
| **成本优势** | 比竞争对手成本更低 | 沃尔玛、Costco |
| **有效规模** | 新进入者无法盈利 | 地区性公用事业 |

### 护城河评估清单

**必须回答的问题**：

1. 如果竞争对手价格一样，你会选这家公司吗？
2. 这家公司涨价10%，用户会流��吗？
3. 如果有人投10亿美元，能复制这家公司吗？
4. 这家公司的优势能维持10年吗？

**评估结果**：

| 护城河强度 | 标志 |
|------------|------|
| 强护城河 | 以上4个问题都是「否」 |
| 中等护城河 | 2-3个「否」 |
| 弱护城河 | 1个「否」或没有护城河 |

---

### 常见护城河陷阱

- ❌ 「技术优势」：技术易被复制
- ❌ 「市场份额」：可能是周期性优势
- ❌ 「政府关系」：政策可能变化
- ❌ 「低价格」：不是可持续优势

## 3. 财务指标解读

### 3.1 ROE（股东回报率）

**公式**：ROE = 净利润 / 股东权益

**杜邦分析**：

```
ROE = 净利率 × 资产周转率 × 权益乘数
    = (净利润/收入) × (收入/资产) × (资产/权益)
```

**判断标准**：

| ROE | 评价 |
|-----|------|
| >20% | 卓越 |
| 15-20% | 优秀 |
| 10-15% | 良好 |
| <10% | 较弱 |

---

### 3.2 盈利能力指标

| 指标 | 含义 | 参考值 |
|------|------|--------|
| 毛利率 | 减去成本后的利润 | >40%优秀 |
| 净利率 | 实际赚钱能力 | >10%优秀 |
| 营业利润率 | 核心业务盈利能力 | >15%优秀 |

---

### 3.3 偿债能力指标

| 指标 | 公式 | 参考值 |
|------|------|--------|
| 资产负债率 | 负债/总资产 | <50%健康 |
| 流动比率 | 流动资产/流动负债 | >1.5健康 |
| 速动比率 | (流动资产-存货)/流动负债 | >1健康 |
| 利息保障倍数 | 息税前利润/利息费用 | >3健康 |

---

### 3.4 成长性指标

| 指标 | 公式 | 参考值 |
|------|------|--------|
| 营收增速 | (本期营收-上期营收)/上期营收 | >10%稳健 |
| 净利润增速 | (本期净利润-上期净利润)/上期净利润 | >10%稳健 |
| 复合增长率(CAGR) | (期末/期初)^(1/年数)-1 | >15%优秀 |

---

### 3.5 现金流指标

| 指标 | 含义 | 参考值 |
|------|------|--------|
| 经营现金流/净利润 | 利润质量 | >80%健康 |
| 自由现金流 | 可分配现金 | 越多越好 |
| 资本开支/折旧 | 维持成本 | <1健康 |

## 4. 风险评估框架

### 4.1 风险分类

| 风险类型 | 子类 | 影响 |
|----------|------|------|
| **行业风险** | 周期下行、政策变化、市场萎缩 | 致命 |
| **竞争风险** | 新进入者、替代品、颠覆式创新 | 致命 |
| **政策风险** | 监管变化、关税、制裁 | 致命 |
| **经营风险** | 管理层、核心人员、供应链 | 严重 |
| **财务风险** | 负债高、现金流断裂 | 致命 |
| **估值风险** | 泡沫破裂、回归合理估值 | 严重 |

### 4.2 风险量化矩阵

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| 行业下行 | 中 | 高 | 减仓/卖出 |
| 竞争加剧 | 高 | 中 | 监控市场份额 |
| 政策变化 | 低 | 高 | 分散持仓 |
| 估值回归 | 高 | 中 | 止盈/止损 |

### 4.3 风险检查清单

**必须检查**：
- [ ] 负债率是否过高？
- [ ] 经营现金流是否为负？
- [ ] 是否有单一客户依赖？
- [ ] 是否有核心技术替代风险？
- [ ] 行业是否夕阳？
- [ ] 管理层是否可信？

## 5. 交易计划模板

### 5.1 仓位管理

| 总仓位建议 | 配置原则 |
|------------|----------|
| 单票上限 | ≤15% |
| 单行业上限 | ≤30% |
| 前5大持仓 | ≤60% |
| 现金储备 | ≥10% |

### 5.2 买入策略

| 方式 | 适用情景 |
|------|----------|
| 一次性买入 | 有把握、确定性高 |
| 分批买入 | 不确定、可更低价 |
| 定投 | 无时间精力管理 |

**分批买入示例**：
```
首笔：30%（现价）
二批：30%（-10%）
三批：40%（-20%）
```

---

### 5.3 止盈止损

| 止盈条件 | 止损条件 |
|----------|----------|
| 涨幅>50% | 跌幅>-20% |
| PE>35x | 跌破关键均线 |
| 基本面恶化 | 出现致命风险 |

**滚动止盈**：
```
涨幅50% → 卖1/3，本金保护
涨幅100% → 再卖1/3
继续持有...
```

---

### 5.4 持有期限

| 持有期限 | 适用情景 |
|----------|----------|
| 1-3个月 | 短线/博弈 |
| 3-12个月 | 中线/趋势 |
| 1-3年 | 长线/价值 |
| 3年以上 | 超长线/核心持仓 |

---

### 5.5 跟踪频率

| 持仓类型 | 检查频率 |
|----------|----------|
| 核心持仓 | 每周 |
| 卫星持仓 | 每两周 |
| 博弈持仓 | 每日 |

**定期审视**：
- 季度报后检查基本面
- 重大事件后立即检查
- 半年度复盘决策逻辑
